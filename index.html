📌 Commandes Git apprises

  • git init - Initialiser un dépôt
  • git add . - Ajouter des fichiers
  • git commit -m "message" - Enregistrer une version
  • git push - Envoyer sur GitHub
  • git log - Voir l'historique

🌿 Pourquoi utiliser des branches ?

Les branches permettent de développer de nouvelles fonctionnalités sans modifier la version stable (main/master).
